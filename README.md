# ✅ To-Do App

A simple and clean **To-Do Application** built using **HTML, CSS, and JavaScript**.  
This app helps users manage daily tasks efficiently by allowing them to add, complete, and delete tasks.

---

## 🚀 Live Demo
🔗 https://rohitraj711.github.io/To-Do-App/

---

## ✨ Features
- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🎨 Clean and responsive UI
- ⚡ Fast and lightweight

---

## 🛠️ Technologies Used
- **HTML5** – Structure
- **CSS3** – Styling & layout
- **JavaScript (Vanilla JS)** – Functionality
